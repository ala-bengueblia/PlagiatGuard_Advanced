Étape 6 — Tester la sécurité et les utilisateurs
Vérifie que le script de génération de JWT est disponible :
python scripts/create_token.py --help


Génère un token pour ton utilisateur existant :
python scripts/create_token.py --username admin


Le mot de passe sera demandé de manière interactive.

Ne partage jamais le token généré et ne l'inscris pas dans le rapport.

Tu peux également vérifier le fonctionnement du module de sécurité :
python -c "from plagiatguard.security import authenticate; print('Module de sécurité importé correctement')"

Étape 8 — Tester les routes de l'API
Ouvre Swagger et clique sur Authorize.

Saisis :
Bearer TON_TOKEN_JWT


Remplace TON_TOKEN_JWT par ton token réel, sans le partager.

Test A : GET /health

Aucune authentification n'est nécessaire.

Résultat attendu :
{
  "status": "ok",
  "version": "2.0.0",
  "research_pipeline": true
}


Attention : ce résultat confirme que le module du pipeline est importable, pas nécessairement que l'index FAISS est effectivement chargé.

Test B : POST /analyze/text

Dans Swagger, utilise :
{
  "text": "Artificial intelligence allows machines to learn from data. Machine learning uses algorithms to identify patterns.",
  "threshold": 0.55
}


Vérifie dans la réponse :
- remaining_quota
- report.adjusted_similarity
- report.flagged
- report.advanced_research.enabled
- report.advanced_research.results.local_matches
- report.similarity_summary.semantic
Test C : POST /analyze/file

Téléverse un fichier TXT, PDF ou DOCX contenant un texte de test.

Vérifie que l'API retourne :
- Le nom du fichier.
- Les résultats du détecteur classique.
- Les résultats de la recherche avancée.
- Les sources correspondantes.
Test D : POST /admin/reload-index

Connecte-toi avec un compte administrateur et lance la requête.

Résultat attendu :
{
  "status": "success",
  "message": "Index de recherche rechargé.",
  "engine": "faiss",
  "passage_count": 2
}


Le nombre de passages dépend de ton index réel.

À ce stade, rappelle-toi que l'interface Streamlit utilise directement le détecteur classique dans le code précédemment examiné. Le lancement de Streamlit ne signifie donc pas que toutes les fonctionnalités sécurisées de FastAPI y sont appliquées.
